# Assets

Brand artwork for this repository. SVGs contain no remote fonts or scripts;
PNG alternatives are provided for tools that reject SVG.

| Path | Use |
|---|---|
| `brand/readme-dark.svg`, `readme-light.svg` | Alternate README banners (not currently displayed) |
| `brand/section-divider.svg` | Gradient divider between README sections |
| `brand/social-dark.png`, `social-light.png` | Repository social preview, 1280 x 640 |
| `brand/icon-dark-256.png`, `icon-light-256.png` | App or avatar use |
| `brand/lockup-*.svg`, `lockup-*.png` | Symbol and wordmark together |
| `justsec/JustSec CI_CD blueprints gradient wordmark.png` | README title wordmark |
| `justsec/justsec-cicd-blueprints.svg`, `.png` | This repository's project icon |
| `icons/*.svg` | Section and card icons, 24-unit viewBox |

Only the blueprints icon belongs to this repository; `justsec-agent-kit.*` is
artwork for a different project and is excluded from publication.

Copy `brand/social-dark.png` into Settings > General > Social preview. Preview
the README in GitHub's light and dark themes before changing the title artwork.

## Style

Colours, gradient direction, radii and type follow the JustSec brand kit
(v1.0.0): Inter 800 for titles, JetBrains Mono for code, dark surface `#0A0F1A`,
and the cyan `#00E5FF` → blue `#3882F6` → purple `#885CFF` → magenta `#D946EF`
gradient. Icons sit on a 24-unit grid at 1.7 stroke, so they hold up from 22 px.
